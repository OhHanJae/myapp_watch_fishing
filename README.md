# 바다한눈 · Wear OS 2.0

갤럭시 워치9 40mm 원형 화면을 위해 새로 구성한 **워치 전용 낚시 정보 앱**입니다. 기존 HTML 화면을 이식하지 않고, 기존 어종·포인트 카탈로그와 예보 로직만 재사용합니다.

## 워치 화면 (일부러 간결하게)

- **홈:** 현재 포인트, 날씨·기온, 파고(큰 숫자), 바람, 수온, 물때(간이 추정), 단순 안전 참고
- **어종 TOP 3:** 현재 포인트·계절·시간·예보 기준 추천 3종과 대표 루어 한 줄씩
- **나침반:** 워치 지자기 센서를 사용한 방위. GPS 위치가 있으면 자기편각 보정으로 진북 표시
- **지역 선택:** `내 위치로` 또는 `포항 → 포인트`, `경주 → 포인트`, `울산 → 포인트`, `부산 → 포인트`

**탭 4개를 한 화면에 쑤셔 넣지 않습니다.** 홈에서 필요한 기능으로 바로 이동합니다. 목록은 `AppScaffold` + `ScreenScaffold` + `TransformingLazyColumn`을 사용하여 손가락 스와이프 및 워치가 제공하는 **터치 베젤/로터리 스크롤 입력**을 지원합니다. 실제 터치 베젤 동작은 워치 시스템의 터치 베젤 설정 및 입력 이벤트 지원에 좌우됩니다.

## 워치 타일 (앱 화면과 다름)

- 워치의 타일 추가에서 **바다한눈 요약**을 선택합니다.
- 포인트 / 파고 / 바람 / 물때(간이 추정) / 추천 1종을 짧게 표시합니다.
- 타일의 **앱 열기**를 누르면 바다한눈 앱이 실행됩니다.
- 타일은 앱이 마지막으로 갱신한 데이터를 읽습니다. **타일 자체에서는 GPS와 인터넷을 호출하지 않습니다.** 앱 데이터가 없거나 45분 넘게 오래됐으면 `예보 갱신 필요`를 표시합니다. 사용자가 앱을 열거나 앱이 새 예보를 받으면 타일 업데이트를 요청합니다. 운영체제가 타일 새로고침 시각을 결정하므로 실시간 상시 갱신을 보장하지 않습니다.

## 빌드/설치

1. Android Studio에서 프로젝트 폴더 열기 → **Gradle Sync**.
2. Android SDK API 36, JDK 17 사용, 인터넷으로 Google Maven 의존성을 받도록 설정.
3. **Build → Make Project** 또는 `app` → 연결한 Galaxy Watch9 → **Run ▶**.
4. 위치 권한을 허용하면 **내 위치 모드**로 시작합니다. GPS를 아직 받지 못했을 때는 임시 기준 포인트임을 표시하고, 임의의 GPS 위치를 만들어내지 않습니다.
5. 홈에서 포인트명을 탭 → 지역/포인트 직접 선택. 홈으로 돌아와 즉시 예보를 요청합니다. 이후 **내 위치로**를 누르면 수동 선택을 지우고 새 GPS 위치를 요청합니다.
6. 타일 추가: 워치 시계 화면에서 왼쪽으로 넘겨 타일 마지막의 `+`/`타일 추가` 또는 Galaxy Wearable의 타일 관리에서 **바다한눈 요약**을 선택합니다. UI는 기기 소프트웨어 버전에 따라 다를 수 있습니다.

## 데이터 기준 및 주의사항

- 실시간 기상/해양 정보: Open-Meteo **수치예보**. 수온은 모델 해수면 온도(SST), 파고는 모델 파고로 실측이 아닙니다.
- `물때*`: HTML 원본의 중국 음력 기반 **간이 물때명 계산**. 한국해양조사원 공식 조석표·만조/간조 확정 시각이 아닙니다.
- 안전 등급은 단순 참고 수치이며 실제 출조 전 풍랑특보·기상특보·출입금지 여부를 확인해야 합니다.
- 어종 추천은 예측 조과 확률이 아니라 기존 가이드 카탈로그의 조건 적합도입니다.
- 원본 데이터: `source/lure_guide.html` → `app/src/main/assets/guide_data.json` (20개 포인트, 15종 어종, 3세트 장비).
