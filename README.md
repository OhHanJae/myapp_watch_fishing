# 바다한눈 · Wear OS 2.2.1

갤럭시 워치9 40mm 원형 화면을 위해 새로 구성한 **워치 전용 낚시 정보 앱**입니다. 기존 HTML 화면을 이식하지 않고, 기존 어종·포인트 카탈로그와 예보 로직만 재사용합니다.

## 워치 화면 (일부러 간결하게)

- **홈:** 타일 스타일의 **실시간 회전 나침반 링**, 바람 방향과 속도에 맞춘 흐름 연출, 예보 파고에 따른 파도 애니메이션. 기온·날씨·수온·파고·물때·물 흐름·추천 1종 표시
- **어종 TOP 3:** 현재 포인트·계절·시간·예보 기준 추천 3종과 대표 루어 한 줄씩
- **12시간 예보:** 30분 간격의 기상/해양 그래프, **절대시각(HH:mm 및 일자)**, 시간별 **1순위 추천 어종 구간 그래프**. 시간대 선택 시 세부 정보
- **지역 선택:** `내 위치로` 또는 `포항 → 포인트`, `경주 → 포인트`, `울산 → 포인트`, `부산 → 포인트`

**탭 4개를 한 화면에 쑤셔 넣지 않습니다.** 홈에서 필요한 기능으로 바로 이동합니다. 목록은 `AppScaffold` + `ScreenScaffold` + `TransformingLazyColumn`을 사용하여 손가락 스와이프 및 워치가 제공하는 **터치 베젤/로터리 스크롤 입력**을 지원합니다. 실제 터치 베젤 동작은 워치 시스템의 터치 베젤 설정 및 입력 이벤트 지원에 좌우됩니다.

## 워치 타일 (앱 화면과 다름)

- 워치의 타일 추가에서 **바다한눈 요약**을 선택합니다.
- 포인트 / 파고 / 바람 / 물때(간이 추정) / 추천 1종을 짧게 표시합니다.
- 타일 테두리에 나침반 눈금과 마지막 측정 방위, **방위에 맞춘 바람 흔적**과 **파고·들물/날물에 따른 파도 호**를 표시합니다. 타일을 누르면 바다한눈 앱이 열립니다.
- 타일은 앱이 마지막으로 갱신한 데이터를 읽습니다. **타일 자체에서는 GPS와 인터넷을 호출하지 않습니다.** 앱 데이터가 없거나 45분 넘게 오래됐으면 `예보 갱신 필요`를 표시합니다. 사용자가 앱을 열거나 앱이 새 예보를 받으면 타일 업데이트를 요청합니다. 운영체제가 타일 새로고침 시각을 결정하므로 실시간 상시 갱신을 보장하지 않습니다. **타일의 나침반 링은 센서 실시간 회전이 아닌 최근 10분 내 앱 홈에서 측정한 마지막 방위의 스냅샷**입니다. 타일 배경 바람/파도는 **예보를 반영한 정적 시각화**이고, **실제 지속 애니메이션은 앱 홈에서만** 실행됩니다. 타일에서 상시 60fps 애니메이션·센서 스트리밍을 구현한 것처럼 표시하지 않습니다.

## 빌드/설치

1. Android Studio에서 프로젝트 폴더 열기 → **Gradle Sync**.
2. Android SDK API 36, JDK 17 사용, 인터넷으로 Google Maven 의존성을 받도록 설정.
3. **Build → Make Project** 또는 `app` → 연결한 Galaxy Watch9 → **Run ▶**.
4. 위치 권한을 허용하면 **내 위치 모드**로 시작합니다. GPS를 아직 받지 못했을 때는 임시 기준 포인트임을 표시하고, 임의의 GPS 위치를 만들어내지 않습니다.
5. 홈에서 포인트명을 탭 → 지역/포인트 직접 선택. 홈으로 돌아와 즉시 예보를 요청합니다. 이후 **내 위치로**를 누르면 수동 선택을 지우고 새 GPS 위치를 요청합니다.
6. 타일 추가: 워치 시계 화면에서 왼쪽으로 넘겨 타일 마지막의 `+`/`타일 추가` 또는 Galaxy Wearable의 타일 관리에서 **바다한눈 요약**을 선택합니다. UI는 기기 소프트웨어 버전에 따라 다를 수 있습니다.

## 데이터 기준 및 주의사항

- 실시간 기상/해양 정보: Open-Meteo **수치예보**. 수온은 모델 해수면 온도(SST), 파고는 모델 파고로 실측이 아닙니다.
- `물때*`: HTML 원본의 중국 음력 기반 **간이 물때명 계산**. 한국해양조사원 공식 조석표·만조/간조 확정 시각이 아닙니다.
- 안전 등급은 단순 참고 수치이며 실제 출조 전 풍랑특보·기상특보·출입금지 여부를 확인해야 합니다.
- 어종 추천은 예측 조과 확률이 아니라 기존 가이드 카탈로그의 조건 적합도입니다.
- 원본 데이터: `source/lure_guide.html` → `app/src/main/assets/guide_data.json` (20개 포인트, 15종 어종, 3세트 장비).

## 2.2 표시 기준

- 그래프 X축: **HH:mm 절대시각**(KST). 그래프 하단의 `MM/dd HH:mm ~ MM/dd HH:mm`으로 자정을 넘는 날짜도 명시합니다.
- 시간별 목록: **MM/dd HH:mm**. 과거 슬롯도 `지금`으로 표기하지 않습니다.
- 어종 그래프: 25개 30분 시점별 **추천 1순위 어종**을 색상 띠로 표시합니다. 이는 조과 확률이 아닌 가이드 순위입니다.
- 바람 방향은 **바람이 불어오는 방향(from)**을 나침반 링에 동기화하고, 앱 배경의 입자는 바람이 흘러가는 쪽으로 이동합니다.
- 파도 진폭은 예보 파고에 비례하고 들물·날물에 따라 색조를 구분하는 **장식적 연출**입니다. 실제 파랑/조류 시뮬레이션이 아닙니다.
- 앱의 독립 나침반 메뉴는 제거하고 **홈의 회전 링**으로 통합했습니다. 백그라운드에서는 센서를 중단합니다.

## Android Studio가 워치를 'non-watch APK'로 경고하는 경우

Android Studio 상단 장치 선택에서 `missing uses-feature watch, non-watch apks cannot be launched on a watch`가 나오면 무선 ADB 문제가 아니라 **프로젝트의 실행 구성 또는 IDE가 참조하는 병합 Manifest** 문제입니다.

이 프로젝트는 이미 `app/src/main/AndroidManifest.xml`에서 `android.hardware.type.watch`를 **필수**로 지정합니다. 이번 수정부터 CI가 **실제로 빌드한 APK의 aapt badging**에서 이를 검사하므로, 이 검사가 성공하는데도 로컬 Android Studio 경고가 남아 있다면 **로컬 IDE 설정·캐시 문제**로 분리할 수 있습니다.

1. `git switch master` → `git pull --ff-only origin master`.
2. Android Studio → **File → Sync Project with Gradle Files** → **Build → Rebuild Project**.
3. 상단 실행 구성에서 공유된 **Wear OS - 바다한눈**을 선택합니다. 기본 **app** 구성과 다릅니다.
4. **Run → Edit Configurations**에서 구성 타입 **Android App**, **Module = `BadaHannunWearOS.app.main` (`:app`)**, **Deploy = Default APK**, **Launch = Default Activity**를 확인합니다. Gradle 프로젝트 명칭이 로컬에서 달라졌다면 목록에서 `:app`에 대응하는 Android 앱 모듈을 다시 선택하세요.
5. 동일 경고가 남으면 편집기에서 `app/src/main/AndroidManifest.xml`을 열고 아래 **Merged Manifest** 탭에서 `android.hardware.type.watch`가 남아 있는지 확인하세요. **Build Variants**의 `app`이 `debug`인지도 확인합니다.
6. 최종 APK 확인은 프로젝트 루트의 PowerShell에서 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\check-wear-apk.ps1`을 한 번 실행하면 됩니다. 이 명령은 코드/워치 설정을 바꾸지 않습니다. SDK 기본 위치는 `D:\AndroidSDK`이며, 다르면 `-SdkRoot` 인자를 지정합니다.
7. APK에 필수 watch 기능이 있는데도 기기 선택 경고가 지속되면 **Run → Edit Configurations**에서 기존 `app` 항목을 삭제하거나 비활성화하고 공유된 새 구성으로 실행하거나, **File → Invalidate Caches / Restart** 후 다시 동기화하세요.

**주의:** GitHub에 정상 APK가 있어도 로컬 Android Studio가 예전 브랜치·잘못된 Run 모듈을 선택 중이면 같은 경고가 계속 나올 수 있습니다. GitHub 수정만으로 모든 PC의 IDE 캐시를 원격 초기화할 수는 없습니다.

## 2.2.1 타일 바람/파도 표시 개선

- **원인:** 이전 타일 구현의 매우 얇은 `ArcLine` 몇 개는 40mm 화면에서 거의 안 보이고, `snap.fresh == false`인 순간 시각 요소를 통째로 생략했습니다.
- **개선:** TileService가 최근의 풍향·풍속·파고·물 흐름으로 **360×360 PNG**를 직접 렌더링합니다. 풍향 위치에는 굵은 파란 화살표와 방향성 흐름을, 하단에는 파고에 따라 진폭과 굵기가 변하는 파도 3줄을 그립니다. 물 흐름(들물/날물)은 색조를 구분합니다.
- **안정성:** Material3TileService의 **`backgroundImage(ImageResource)`와 자동 이미지 리소스 등록**을 사용합니다. 별도로 `onTileResourcesRequest`를 오버라이드하지 않습니다.
- **누락/오래된 예보:** 그래픽 기본 구조는 항상 표시합니다. 해당 값이 없으면 중립적인 연출로 표현하고 수치는 `--`로 보여줍니다. 데이터가 오래되면 색상이 약해지고 `이전/미수신 예보 · 앱 갱신` 표시가 나옵니다. 미수신값을 풍속 0m/s, 파고 0m로 가장하지 않습니다.
- **나침반:** 타일은 마지막으로 앱 홈에서 받은 방위를 최대 10분 동안 사용합니다. 방위가 없으면 북쪽을 위로 둔 나침반으로 표시하고 텍스트로 구분합니다. **타일은 연속 애니메이션/실시간 센서가 아닙니다.** 앱 홈에서만 실시간 바람/파도 연출을 보여줍니다.

업데이트 후 워치에서 앱을 실행해 **예보 새로고침**한 뒤 타일을 다시 확인하세요. 기존 타일이 캐시를 계속 표시한다면 타일을 제거한 다음 재추가할 수 있습니다. 타일 프리뷰 이미지와 실제 타일 화면은 다를 수 있습니다.

## 2.2.2 타일 고정 북쪽 · 테마 · 지역 순서

- **타일 나침반:** 정적 타일은 N(북) 상단, E(동) 오른쪽, S(남) 하단, W(서) 왼쪽으로 **항상 고정**합니다. 마지막 센서 방위를 저장해 돌리던 로직을 제거했습니다.
- **풍향:** 고정된 북쪽을 0°로 삼아 예보의 풍향(from)을 화살표로 나타냅니다. 타일이 실제 기기 방향을 따라가는 나침반은 아닙니다.
- **화면 설정:** 앱 홈 맨 아래 **화면 · 타일 테마** → 앱 화면 화이트/다크, 워치 타일 화이트/다크/앱 설정에 따름을 선택. 즉시 저장하고 타일 갱신을 요청합니다.
- **앱 설정에 따름:** 타일 색상이 앱 화이트/다크 설정을 따라갑니다. 기본 앱은 다크, 타일은 앱 설정에 따름입니다.
- **지역 목록:** 내 위치로 버튼 아래 지역이 **울산 → 경주 → 포항 → 부산**. 울산은 **슬도·방어진항 → 주전항·주전 해안 → 당사·강동 해안권 → 나머지** 순서입니다. 원본 좌표·어종 데이터는 변경하지 않습니다.
- **앱 홈:** 실시간 센서 나침반은 그대로 유지하고 타일 방향만 고정합니다.

기타 PR을 병합할 때는 app/build.gradle.kts의 versionCode/versionName 충돌을 주의해 최신 값을 유지하세요.

## 2.2.3 타일 네모 배경 제거 · 파도 한 줄 · 방위 문자 강조

- **타일:** 기상 정보 뒤의 사각형 배경/테두리를 완전히 제거했습니다. 기존 화이트/다크 배경과 중앙의 기상 정보는 유지됩니다.
- **타일 파도:** 기존 3개의 개별 파도 선을 **하나의 연속 경로**로 교체했습니다. 선은 나침반의 왼쪽 테두리에서 시작해 오른쪽 테두리까지 이어지고, 파고 예보에 따라 잔물결 진폭이 변합니다.
- **앱 홈 파도:** 같은 하나의 곡선을 사용합니다. 애니메이션은 앱 홈에만 적용되고 타일은 정적입니다.
- **앱 나침반:** N은 **빨강**, S는 **파랑**, E/W는 **검정** 문자를 흰색 원형 마커 위에 표시합니다. 검정 문자가 다크 테마에서 사라지지 않도록 흰색 마커를 사용합니다. 실시간 방위 센서에 따라 문자 위치는 나침반과 함께 회전합니다.
- **기본 데이터:** 물때·날씨·추천 어종과 지역 선택 로직은 변경하지 않습니다. 파도 효과는 파고 모델값에 기반한 시각 효과이고 실제 바다 영상이 아닙니다.


## 2.2.4 워치 첫 화면·타일 문구·나침반 눈금 개선

- **타일 N↑ 고정 · 풍향은 북 기준 안내문 제거**: 기존 다른 정보들의 수직 위치가 바뀌지 않도록 마지막 한 줄은 내용이 보이지 않는 공백(동일한 글꼴·행 높이)으로 유지합니다.
- **나침반 문자 제거**: 타일과 앱 모두 N/E/S/W 문자를 그리지 않습니다. 큰 방위 눈금의 색상으로 방향을 구분합니다. **북 빨강, 남 파랑, 동·서 검정**이며 검정 눈금에는 흰색 아래 선을 넣어 다크 테마에서도 보이게 했습니다.
- **첫 화면을 나침반 중심으로 변경**: 앱에 들어가면 제목이나 위치 선택 카드보다 **전체 화면 크기의 나침반**이 먼저 표시됩니다. 아래로 스크롤해야 **지역 · 포인트** 선택과 12시간 예보·테마 설정이 나타납니다. 기존 터치 베젤 스크롤 방식을 유지합니다.
